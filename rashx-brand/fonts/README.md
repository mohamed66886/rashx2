# Typography — Ping AR + LT (Dual-Weight Architecture)

| Style | Weight | File | Use |
|---|---|---|---|
| Light / Regular | 300 – 500 | `PingAR+LT-Light.otf` | Body text, cards, descriptions, UI labels |
| Bold / ExtraBold | 600 – 900 | `PingAR+LT-Bold.otf` | Headlines, display, SectionTitle, buttons, emphasis |

- خط `Ping AR + LT` الرسمي معتمد في المنصة بوزنين رئيسيين: Light للنصوص والفقرات، و Bold للعناوين والأزرار.
- ملفات الخط موجودة ومفعّلة تلقائياً في `fonts.css` و `apps/web/src/app/globals.css`.
- ملفات SVG والـ HTML فيها نص حي بخط `Ping AR + LT`.
- قبل الطباعة النهائية: حوّل النص لـ outlines (Create Outlines في Illustrator / Convert to Path في Inkscape) عشان الخط يتثبّت.
- اللوجوهات نفسها paths، مش متأثرة بالخط.
